# Dự án người thứ 2 - Quản lý sách và nhập kho

Dự án này dành riêng cho thành viên thứ 2 trong nhóm.

## Chức năng chính
- Quản lý danh mục sách
- Tìm kiếm sách
- Thêm, sửa, xóa sách
- Nhập sách mới
- Kiểm tra quy định số lượng nhập và tồn kho
- Xem lịch sử phiếu nhập

## Cấu trúc
- `api/` : backend PHP
- `frontend/` : giao diện web
- `database/` : file SQL mẫu

## Cài đặt nhanh
1. Tạo database `QuanLyNhaSach` trong MySQL
2. Import file `database/schema.sql`
3. Đặt thư mục này vào `htdocs` hoặc thư mục chạy PHP của bạn
4. Truy cập: `http://localhost/Quanlymuontrasach_Nguoi2_BookInventory/`

## Mục tiêu học tập
- CRUD API
- Kết nối PHP + MySQL
- Frontend JavaScript + AJAX
- Quản lý tồn kho và phiếu nhập
